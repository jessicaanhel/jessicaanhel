anhel-frontend-library

The best parts of our wedding website, as React components you can drop into another site. I took them out of the wedding code and made them data-driven: you pass the photos, dates and texts as props.

terminal
npm install ../anhel-frontend-library
npm install react react-dom framer-motion
See the components Ask about it

What is inside

Three components and one small Node tool. They are shipped as source, with no build step. Your app's bundler compiles the TypeScript and the CSS modules, so it works the same in Next.js and in Vite.

Each component renders a plain <img> by default. Pass a renderImage function and it uses next/image or anything else instead.

  • 3 components, each with its own import path
  • 1 image tool, with no npm packages
  • 6 smoke tests that render every component on the server

The components

The screenshots below are a small demo page I made for this case study, with the library's example frame, heart and rings. The photos are placeholders.

anhel-frontend-library/video-entry

VideoEntry

The first screen is a closed envelope. Tap it, and a video plays and the music starts. Halfway through, the envelope blurs away and the page is already there underneath. A small floating button turns the music on and off.

  • React 18+
  • framer-motion 11+
  • client component
tsx
<VideoEntry
  closedImageSrc="/images/envelope-closed.png"
  videoSrc="/videos/entry.mp4"
  audioSrc="/audio/music.mp3"
  texts={{ tapToOpen: "Tap to open" }}
  aspectRatio="1.132 / 1"
  wrapper={SitePanel}
>
  <MyPage />
</VideoEntry>

anhel-frontend-library/framed-photo-stack

FramedPhotoStack

Photos in oval frames that slide over each other while you scroll. Each one gets a small tilt and a sideways shift, so the pile looks like real prints on a table. The movement is pure CSS position: sticky, with no scroll listener.

  • React 18+
  • no client code
tsx
<FramedPhotoStack
  photos={[
    { src: "/images/story/1.jpg", alt: "First trip" },
    { src: "/images/story/2.jpg", alt: "Engagement" },
  ]}
  frameSrc="/images/floral-frame.png"
/>

anhel-frontend-library/schedule-timeline

ScheduleTimeline

The program of the event. A thin golden thread grows down the page as you scroll, with the rings sliding along its end. Above it, a sticky strip shows the days, and a gold heart moves to the day you are reading. Tap a number to jump to that day.

  • React 18+
  • framer-motion 11+
  • client component
tsx
<ScheduleTimeline
  eyebrow="The program"
  heading="How the day unfolds"
  heartSrc="/images/heart-gold.png"
  pendantSrc="/images/rings-gold.png"
  edgeDays={{ before: 9, after: 14 }}
  days={[
    { date: "2027-06-11", items: [
      { time: "18:00", title: "Welcome drinks",
        description: "On the terrace" } ] },
  ]}
/>

tools/cut-frame-interior.mjs

A tool for the frames

A photo can only sit behind a frame if the inside of the frame is transparent. This script cuts the solid inside of a frame image away and prints the clip-path that fits the hole. It is how the floral frame above was made. It needs Node 18+ and ffmpeg, and no npm packages.

terminal
# 1. Look at the colours first: fill, petals, outline
node tools/cut-frame-interior.mjs frame.png --sample "700,1000;650,400"

# 2. Cut the inside out
node tools/cut-frame-interior.mjs frame.png frame-cut.png
#   -> suggested clip-path: ellipse(45.1% 35.0% at 50.0% 49.2%)

Fits into your site

Fonts and colours come from CSS custom properties, with fallbacks. Set them once on :root and the components follow your design. The timeline also takes your own class names for its section and heading.

css
:root {
  --font-display: "Cormorant Garamond", serif;
  --paper: #fbf5ea;   /* behind the date strip */
  --accent: #b08d4f;  /* times and eyebrow */
  --ink-soft: #837e70;
  --schedule-sticky-top: 3.6rem;
}

Decisions I made

Source, not a build
The package exports the .ts files directly. There is no dist folder to keep in sync, and each app compiles the components with its own settings. The README shows the two lines Next.js needs for this.
The video and music never remount
The <video> and <audio> elements stay in the same place in the tree in every stage. If React remounted them, the video would jump back to the start and the music would stop in the middle of the dissolve.
Music starts from the tap
Browsers only play sound that starts from a user gesture. So the same tap that opens the envelope also starts the music.
The page keeps its state
On the wedding site the page was mounted again when the dissolve finished. In the library it has one stable slot, so nothing on the page is reset by the intro.
Tilts that are the same every time
The photo angles come from a small formula on the index, not from Math.random. The server and the browser draw the same pile, and it does not reshuffle on every visit.
A colour window, not a colour distance
The frame tool first removed every pixel close to the cream fill. The pale pink petals were too close and got eaten. Now it checks brightness and the gaps between red, green and blue, which keeps the petals and the leaves.
Small guards for real data
An empty program renders nothing instead of crashing, and the timeline survives a change in the number of days.
