Case study · one-page website

A quiet, one-page website for a life manager in Berlin.

Polina helps people with identity, presence and personal direction. I built her site: one page that explains what she does, how you can work with her, and how to write to her. It is plain HTML and CSS, with a light and a dark theme.

What is on the page

Five parts, top to bottom: the promise, what makes her different, the topics she works on, the three ways to work with her, and a short about. It ends with one clear next step: write an email.

On a phone

The rows stack into one column and the menu goes away. The brand and the booking button stay at the top.

Light and dark

The page follows the visitor's system setting. In the dark, the paper turns into a deep plum and the wine red gets lighter, so it is still easy to read.

Decisions I made

One file, no build
The whole site is one HTML file with the CSS inside it. There is no JavaScript and no framework. It loads fast and any static host can serve it.
A brand, not a coaching site
Polina says she is not a coach and not a therapist. So no soft gradients or stock photos: a cream paper colour, a wine red, a serif for headlines and a typewriter font for small notes.
Rows instead of cards
Topics and formats sit in rows with thin lines between them, like a list in a notebook. On small screens each row becomes one column.
A seal instead of a logo
The round mark is drawn in SVG, with her name and words set along a circle. It turns very slowly. If the visitor asks for less motion, it stands still, and so does the fade-in of the first screen.
Colours as variables
All colours live in a few CSS variables. The dark theme only changes those values, so there is one set of styles to maintain.
Search basics in place
A clear title and description, a canonical link, social preview tags, a robots.txt and a sitemap. Structured data describes Polina as a person and lists her three services.

Built with HTML, CSS and inline SVG. Fonts: Instrument Serif, IBM Plex Sans, IBM Plex Mono.
