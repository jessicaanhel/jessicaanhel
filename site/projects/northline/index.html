Decisions I made

Small choices that keep it simple

Prices and projects live in data files
The packages, extras, questions and concept projects are plain lists in src/data. The Home page shows the first two projects, the Work page shows all of them. Changing a price means changing one line, not a component.
Honest about being new
There are no client case studies yet, and the site says so. Every sample card has a "Concept project" label, and the prices are marked as ranges that are agreed before work starts.
A contact form without a server
The form opens the visitor's email app with the name, business and message already filled in. If nothing opens, a line under the button shows the email address. No backend, nothing to keep running.
Search basics on every page
A small component sets the title, description, canonical link and social sharing tags when the page changes. The Services page also builds FAQ structured data from the same list of questions it shows. There is a sitemap and a robots.txt.
One place for colours and fonts
Navy, one blue accent, a light grey surface and two fonts (Manrope for headings, Inter for text) are set once in the Tailwind theme. Buttons have three styles, all fully round, so every page looks like the same studio.
One clear action
"Get a quote" sits in the header and at the end of each page. On a phone it moves into the folded menu, so it is never more than one tap away.

Built with React, TypeScript, Vite, Tailwind CSS v4 and React Router. The build is a set of static files.
