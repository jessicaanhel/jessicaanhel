IT'S me...

An online shop for a yoga and pilates clothing brand.

I built the whole shop as one Next.js app: the catalogue, product pages, a basket, favourites and customer accounts. It uses the brand's strawberry and matcha colours from the first screen to the checkout.

What is inside

For shoppers: a home page with bestsellers and new items, a shop with three categories and sorting by price, product pages with colour and size, a basket and a list of favourites. All of this works without an account.

With an account: saved addresses, saved cards, order history and a checkout. The basket and favourites move with you to any device after you sign in.

  • 16 demo products in 3 categories
  • 0 external services: the data lives in JSON files
  • 1 app for the pages and the API

Decisions I made

Shop first, account later
A guest can fill the basket and save favourites. They stay in the browser. When the guest signs in or signs up, the shop merges them with what the account already has, so nothing gets lost.
Same item, same line
The basket treats product, colour and size together as one line. Adding the same leggings in the same size again raises the amount; a different size is a new line. This rule has its own tests.
JSON files instead of a database, for now
Products, users and newsletter sign-ups live in JSON files, so the shop runs with no setup. Every read and write goes through one small file of functions. Moving to a real database means rewriting only those functions, not the pages.
Card details are never stored
Saved cards are only a mock for now. The server keeps the brand and the last four digits and throws away the rest. The checkout does not take real payments.
Safe sign-in without extra services
Passwords are hashed with bcrypt. The session is an encrypted, httpOnly cookie, so page scripts cannot read it.
The brand lives in a few tokens
Cream, matcha, strawberry and charcoal, Playfair for headings and Inter for text, all set once in the theme. Pink is for actions, green is for the footer and the basket badge.

Built with Next.js (App Router), TypeScript, Tailwind CSS, Zustand, iron-session and bcrypt. Tested with Vitest.
